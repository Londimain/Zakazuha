# Заказуха (Zakazuha)

**Заказуха** — это профессиональная программа для автоматизации работы с прайс-листами и формирования заявок на закупку. Программа позволяет осуществлять молниеносный поиск товаров по базам разных поставщиков, гибко настраивать заявки, выгружать их в Excel и вести общую базу отчётов.

Приложение рассчитано на работу в небольшой команде с возможностью использования как локальной, так и общей сетевой базы данных (SQLite).

## 🚀 Основные возможности

* **Умный поиск:** Быстрый поиск по названию и артикулу по всем загруженным базам поставщиков (TDM, IEK, а также свои прайсы). Поддержка пакетной вставки артикулов из буфера обмена (Excel).
* **Защита от дубликатов:** При добавлении товара, который уже есть в заявке, программа не создает новую строку, а автоматически увеличивает его количество.
* **Свои прайс-листы:** Возможность добавления собственных прайсов по прямой ссылке (URL) или из локального файла (`.xls`, `.xlsx`). Доступ к редактированию защищён паролем.
* **Гибкая работа с заявкой:** Добавление товаров, ручное редактирование количества, перетаскивание строк мышкой для изменения порядка. Умная защита от случайной перезаписи данных при редактировании существующих отчётов.
* **Настройка выгрузки в Excel:** Выбор конкретных колонок (Артикул, Наименование, Кол-во и т.д.) и полей шапки документа.
* **Сохранение состояния:** Незавершённая заявка (черновик) и состояние редактирования конкретного отчёта автоматически сохраняются при выходе. После перезапуска вы сможете продолжить с того же места.
* **Продвинутая база отчётов:** Все созданные заявки хранятся в базе данных. Встроен мгновенный поиск (без нажатия Enter) по контактам, организациям и примечаниям. Доступен фильтр по диапазону дат. Отчёты можно объединять в сводные ведомости.
* **Безопасность:** 
  * Вход в программу защищён паролем. Пароли хранятся в виде криптографических хешей (PBKDF2 с солью), что исключает их кражу.
  * В «Настройках» реализована удобная смена пароля на вход и пароля администратора.
  * Запрещён одновременный запуск двух копий программы (второй запуск просто развернёт уже открытое окно).
  * Строгая проверка пути к сетевой базе данных (программа не создаст пустую базу в неверной папке, а выдаст ошибку).
* **Автообновление:** Программа автоматически проверяет наличие новых версий в сетевой папке при запуске и предлагает обновиться в один клик (с автоматическим закрытием текущей версии). Также есть кнопка ручной проверки на вкладке «О программе».
* **Темы оформления:** 3 встроенные темы (Светлая, Тёмная, Синяя) и полностью настраиваемая «Своя тема».
* **Сетевая работа:** В «Настройках» можно указать путь к общей базе данных (файлу `cache.db`) для работы в команде.

## 🛠 Технологический стек

* **Язык:** Python 3
* **GUI:** PySide6 (Qt for Python)
* **База данных:** SQLite3
* **Работа с Excel:** `pandas`, `openpyxl`, `xlrd`
* **Сеть:** `requests`
* **Безопасность:** `hashlib`, `binascii` (PBKDF2)

## 📦 Установка и запуск (для разработки)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Londimain/Zakazuha.git
   cd Zakazuha
   ```

2. Запустите скрипт автоматической настройки окружения (Windows):
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\setup_env.ps1
   ```
   *Скрипт создаст виртуальное окружение `venv`, активирует его и установит все зависимости из `requirements.txt`.*

3. Запустите приложение:
   ```bash
   python main.py
   ```

## 📖 Принцип работы

0. **Авторизация:** При запуске введите пароль для доступа к программе (по умолчанию `*****`).
1. **Прайсы:** Настройте источники (включая свои) и нажмите «Обн.» для загрузки актуальных цен в базу.
2. **Поиск:** Введите название или артикул, выберите нужное галочками и нажмите «Добавить отмеченные» (или используйте кнопку «Вставить артикулы» для списка).
3. **Заявка:** Измените количество, перетащите строки для сортировки или удалите лишнее. Программа сама отследит дубликаты.
4. **Отчёт:** Нажмите «Создать отчёт». Заявка сохранится в базу и появится на вкладке «Отчёты». Если нужно дополнить отчёт, выберите его и нажмите «Добавить \ Удалить».

> **Важно:** 
> * Пароль для входа в программу по умолчанию: `*****`.
> * Пароль администратора для удаления отчётов и управления прайс-листами по умолчанию: `*****`.
> * Сменить оба пароля можно в разделе **Настройки -> Безопасность**.

## 🏗 Сборка и публикация

Проект использует связку **PyInstaller** (сборка в EXE) и **Inno Setup** (создание установщика).

1. **Сборка приложения:**
   Соберите EXE-файл с помощью PyInstaller (файл `Zakazuha.exe` должен находиться в папке `dist`).

2. **Создание установщика:**
   Откройте файл `manager_installer.iss` в программе Inno Setup и скомпилируйте его. Готовый установщик появится в папке `installer_output`.

3. **Публикация обновления:**
   Используйте утилиту **`publisher.py`** (Публикатор обновлений):
   * Укажите новую версию (например, `2.1.3`) и нажмите кнопку для обновления файлов `version.py`, `version_info.txt`, `manager_installer.iss` и `version.json`.
   * Укажите сетевую папку (ту же, где лежит база данных `cache.db` для клиентов).
   * Нажмите «Скопировать установщик и обновить version.json в сети». Скрипт сам скопирует новый установщик, удалит старые сборки и обновит файл конфигурации для автообновления у клиентов.
