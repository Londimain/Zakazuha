# Заказуха (Zakazuha)

**Заказуха** — настольное приложение для автоматизации работы с прайс-листами поставщиков и формирования заявок на закупку. Программа позволяет быстро искать товары по нескольким базам, собирать заявку с защитой от дубликатов, выгружать её в Excel и вести общую базу отчётов. Рассчитана на работу в небольшой команде с возможностью использования как локальной, так и общей сетевой базы данных (SQLite).

## 🚀 Возможности

- **Умный поиск** по названию и артикулу сразу по всем загруженным базам (TDM, TDM_img, IEK, IEK_svet и пользовательским). Поддержка пакетной вставки списка артикулов из Excel через буфер обмена.
- **Защита от дубликатов:** при добавлении товара, который уже есть в заявке (совпадают артикул и источник), программа не создаёт новую строку, а увеличивает количество.
- **Свои прайс-листы:** добавление источников по прямой ссылке (URL) или из локального файла `.xls`/`.xlsx`/`.xlsm`/`.zip`. Автоматическое распознавание колонок «Артикул», «Наименование», «Цена», «Упаковка», «Ед.», «GTIN».
- **Работа с заявкой:** чекбоксы, перетаскивание строк мышкой, ручное добавление и редактирование, сохранение черновика.
- **Настройка выгрузки в Excel:** выбор отображаемых колонок таблицы и полей шапки документа.
- **Отчёты:** все созданные заявки хранятся в базе. Есть мгновенный поиск (без Enter) по организации/контактам/ФИО/примечанию, фильтр по диапазону дат, объединение нескольких заявок в сводную ведомость, редактирование шапки и состава товаров.
- **Сохранение состояния:** незакрытая заявка (черновик) и состояние редактирования конкретного отчёта автоматически сохраняются при выходе и восстанавливаются при следующем запуске.
- **Темы оформления:** три встроенные темы (Светлая, Тёмная, Синяя) и полностью настраиваемая «Своя тема».
- **Сетевая работа:** в настройках указывается путь к общему файлу `cache.db` на сетевом диске. В статус-баре отображается, используется локальная или сетевая база.
- **Автообновление:** проверка новой версии в сетевой папке при запуске (по `version.json`) и ручная проверка на вкладке «О программе», с прогресс-баром и запуском установщика.
- **Запрет второго экземпляра:** повторный запуск не открывает новое окно, а разворачивает уже работающее.
- **Безопасность:** вход в программу и опасные операции (например, удаление отчёта) защищены паролем. Пароли хранятся только в виде криптографических хешей PBKDF2-SHA256 с солью.

## 🛠 Технологический стек

- **Python 3.10+**
- **PySide6** — графический интерфейс
- **SQLite3** — локальная/сетевая база данных
- **pandas**, **openpyxl**, **xlrd** — чтение и запись Excel-файлов
- **requests** — загрузка прайс-листов и обновлений
- **hashlib / binascii (PBKDF2)** — хранение паролей
- **PyInstaller** — сборка `.exe`
- **Inno Setup** — сборка установщика
- **tkinter** — только для утилиты `publisher.py` (публикатор обновлений)

## 📦 Установка (для разработки)

Требуется Windows и Python 3.10+.

```bash
git clone https://github.com/Londimain/Zakazuha.git
cd Zakazuha
```

**Вариант 1 — через скрипт (PowerShell):**

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup_env.ps1
```

> ⚠️ В конце `setup_env.ps1` есть проверочная строка, которая импортирует `kivy`/`kivymd`. Эти библиотеки в проекте не используются — если увидите ошибку на последнем шаге, она безопасна и на работу приложения не влияет.

**Вариант 2 — вручную:**

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## ▶️ Запуск

```bash
python main.py
```

При первом запуске в каталоге `%APPDATA%\Заказуха\` создаются:

- `config.json` — настройки (тема, выбранные источники, путь к БД);
- `draft.json` — черновик заявки;
- `editing_order.json` — состояние редактирования отчёта;
- `prices/` — скачанные прайс-листы;
- `updates/` — загруженные установщики обновлений.

При старте программа запрашивает пароль. Пароль на вход и пароль администратора задаются при первой инициализации, хранятся в `config.json` **только в виде PBKDF2-хешей** и могут быть изменены в разделе **Настройки → Безопасность**. В самом репозитории и в этой документации пароли не публикуются.

## 📖 Принцип работы

0. **Запуск:** введите пароль для доступа к программе.
1. **Прайсы:** настройте источники (включая свои) и нажмите «Обн.» для загрузки актуальных цен.
2. **Поиск:** введите название или артикул, отметьте нужные галочками и нажмите «Добавить отмеченные» (либо «Вставить артикулы» для списка из буфера).
3. **Заявка:** измените количество, перетащите строки для сортировки, удалите лишнее. Дубликаты обрабатываются автоматически.
4. **Отчёт:** нажмите «Создать отчёт». Заявка сохранится в базу и появится на вкладке «Отчёты». При необходимости отчёт можно снова открыть («Добавить \ Удалить»), отредактировать шапку или объединить с другими в сводную ведомость.

## 🏗 Сборка и публикация

Проект использует связку **PyInstaller** + **Inno Setup**, а публикация обновлений автоматизирована утилитой **`publisher.py`**.

### 1. Сборка EXE

```bash
pyinstaller Zakazuha.spec
```

Готовый файл появится в `dist/Zakazuha.exe`. В спеке уже настроены:
- `console=False` — приложение запускается без консольного окна;
- `upx=True` — сжатие UPX (если установлен);
- иконка `ico/app.ico`;
- исключены лишние модули (tkinter, matplotlib, scipy, IPython, Jupyter, pytest, часть PySide6-модулей), чтобы уменьшить размер сборки.

### 2. Создание установщика

Откройте `manager_installer.iss` в Inno Setup и скомпилируйте. Установщик появится в `installer_output/Zakazuha_Setup_v<версия>.exe`.

### 3. Публикация обновления

Запустите `publisher.py` (или собранный `Заказуха Publisher.exe`). Утилита:

1. По кнопке «Обновить файлы» синхронизирует версию в `version.py`, `version_info.txt`, `manager_installer.iss` и локальном `version.json`.
2. По кнопке «Скопировать установщик и обновить version.json в сети»:
   - копирует новый установщик в сетевую папку;
   - удаляет старые сборки (и в сети, и локально);
   - обновляет `version.json` (в том числе накапливает историю релизов в массиве `history`).

Клиенты при следующем запуске увидят уведомление о новой версии и смогут обновиться в один клик.

## 🔐 Безопасность

- Пароли входа и администратора хранятся **только** как PBKDF2-SHA256-хеши с уникальной солью (100 000 итераций). В открытом виде в конфигурации, репозитории и логах они не фигурируют.
- Смена паролей — в разделе **Настройки → Безопасность**.
- Удаление отчётов требует ввода пароля администратора.
- Запрещён одновременный запуск двух копий (реализовано через `QLocalServer`/`QLocalSocket`).
- При указании сетевой базы программа проверяет существование файла и не создаёт пустую БД в неверной папке.

## 🤝 Совместимость и известные ограничения

- Основная целевая платформа — **Windows 10/11** (используются `ctypes.windll`, `os.startfile`).
- Для сетевого режима требуется общий доступ к файлу `cache.db` на сетевом диске; одновременное обновление одного источника блокируется через файл `update.lock`.
- Встроенные источники прайсов (TDM, IEK) недоступны без интернета; можно использовать локальные файлы и собственные URL.
